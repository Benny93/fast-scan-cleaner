What you get

Everything works out of the box — no terminal knowledge required.

🗺️ Map of your disk

A treemap where big blocks are big folders and files, filling in live while scanning. Click to zoom, browser-style back/forward, right-click to select several blocks and trash them in one go.

Plain-language advice

Every block is colour-coded: green = safe to remove, yellow = check first, red = keep. Comes with a curated rules catalog — Xcode caches, Docker data, iOS backups, node_modules, …

🗑️ Nothing is deleted

Removals go to the Trash, so you can restore them. Only the optional system tools delete permanently — empty Trash, Homebrew and Docker cleanup, old simulators, stale Git worktrees — and they always ask first.

🤖 AI assistant support (MCP)

Let Qoder, Claude or another assistant explore your disk with you, see what you see, and propose things to remove. It can never remove anything without your confirmation.

🌍 Comfortable defaults

Six languages (English, Deutsch, Français, Español, 中文, 日本語), light/dark/system theme, and recent scans at a click.

Install

Grab an installer from the latest release, or use your package manager.

macOS — Homebrew

brew install --cask benny93/tap/fastscancleaner

The fully-qualified name trusts only this cask, not the whole tap.

Windows — winget

winget install Benny93.FastScanCleaner

Linux

# .deb and .AppImage in the latest release,
# built on old glibc so they run on most distros.

First launch: installers are unsigned. On macOS, after installing run xattr -dr com.apple.quarantine "/Applications/FastScanCleaner.app" once. On Windows, SmartScreen shows "unknown publisher" — click More info → Run anyway. The app itself is fine.

Connect an AI assistant

Turn on Allow AI assistants to control this app in Settings, restart, then point your client at the local server:

claude mcp add --transport http fastscancleaner http://127.0.0.1:7878/mcp

The server listens on 127.0.0.1 only (default port 7878) and rejects requests from other hosts. Every removal stays behind your confirmation in the app — there is deliberately no tool to change settings or the allowlist.
